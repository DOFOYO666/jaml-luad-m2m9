# Code for: Compartmentally separated JAML and CXADR in lung adenocarcinoma: myeloid-dominant expression, and ID2 as the only noise-calibrated candidate regulator

Release 1.0.0 (2026-10-01) — every number, figure and table in the manuscript is generated by the
scripts in `code/`. Derived tables are in `results/`; the numbered supplementary files are in
`supplementary/`.

## What this repository contains

The study asks where *JAML* acts in lung adenocarcinoma and who regulates it, using public data
only. It does not report a new Mendelian randomisation estimate. The eight analyses and their
controls are listed in Table 1 of the manuscript; the text of the manuscript states explicitly
which claims the data do not support.

## Reproducing

Python 3.13 with `pandas`, `numpy`, `scipy`, `scanpy`, `anndata`, `decoupler`, `celloracle`,
`liana`; R 4.6 with `survival`, `data.table`, `ggplot2`. `celloracle` additionally requires
`velocyto`, which has no Windows wheel on PyPI — it was built locally from source with Cython
3.3.0 and Rtools44 GCC 13.3.0 (`code/40_verify_velocyto_minimal.py` verifies it against a NumPy
reference implementation, max |delta| = 8.9e-16).

Scripts read data from a project-local `rawdata/` tree and write to `results/`; paths appear as
module constants at the top of each file. The M4 cell-oracle figures are re-plotted (rather than
re-fitted) by `code/m8_fig6_replot.py`, which reproduces the pipeline's own saved values — it
asserts the recomputed permutation distribution equals the recorded one before writing a figure.

## Two things a reader should know about our controls

1. `calculate_randomized_coef_table()` in CellOracle caches its randomised coefficient matrix
   (default seed 123, computed once). Repeating a call without changing the seed re-uses the same
   randomised network. Our paired control therefore re-seeds on every replicate.
2. The global noise ceiling is the largest randomised reading observed across non-degenerate
   factors — an empirical maximum over a finite number of draws. It sits below the true null
   maximum, so the screen is liberal, not conservative; and with five replicates per factor no
   empirical P value below 1/6 is attainable. What carries weight is the size of the excess.
